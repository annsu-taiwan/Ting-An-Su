# Conditional-AAD grids (9x9)

Each `.npz` file holds the precomputed conditional-AAD grid of one WWR scenario for the Citigroup calibration. The grids are generated by `build_citi_joint_grid.py` (about 3-4 hours per scenario) and are only read by the notebooks.

## Scenarios

The correlation pair is $(\rho_{r,\lambda},\rho_{copula})$, where $\rho_{r,\lambda}$ is the diffusive spread correlation and $\rho_{copula}$ is the jump-to-default correlation. In the two `mixed` file names the two numbers in parentheses follow the same order, for example `(04,08)` means $\rho_{r,\lambda}=0.4$ and $\rho_{copula}=0.8$.

| File (`dual_wwr_joint_grid_citi_<name>_monthly.npz`) | $\rho_{r,\lambda}$ | $\rho_{copula}$ | Label in the notebook | Builder argument |
|---|---|---|---|---|
| `independent` | 0.0 | 0.0 | Independent | `independent` |
| `diff_04` | 0.4 | 0.0 | Diffusion(0.4/0.0) | `diff_04` |
| `diff_08` | 0.8 | 0.0 | Diffusion(0.8/0.0) | `diff_08` |
| `jump_04` | 0.0 | 0.4 | Jump(0.0/0.4) | `jump_04` |
| `jump_08` | 0.0 | 0.8 | Jump(0.0/0.8) | `jump_08` |
| `wwr` | 0.4 | 0.4 | WWR(0.4/0.4) | `wwr` |
| `wwr_strong` | 0.8 | 0.8 | WWR(0.8/0.8) | `wwr_strong` |
| `mixed_(04,08)` | 0.4 | 0.8 | Mixed-A(rl=0.4,cop=0.8) | `mixed_a` |
| `mixed_(08,04)` | 0.8 | 0.4 | Mixed-B(rl=0.8,cop=0.4) | `mixed_b` |

## Contents of a file

All grid arrays are indexed `[date, x_r node, x_lambda node]`, with 131 monthly rebalancing dates (4 weeks apart, from $t=0$ to $t=10$ years) and $9\times9=81$ nodes per date.

| Array | Shape | Content |
|---|---|---|
| `cva_grid` | (131, 9, 9) | Remaining CVA from the node's date, conditional on $(x_r,x_\lambda)$ (1,000 fresh sub-paths per node) |
| `delta_R_grid` | (131, 9, 9) | Parallel rate delta, the sum of $\partial CVA/\partial R_h$ over the SOFR/OIS pillars |
| `delta_L_grid` | (131, 9, 9) | Parallel credit delta, the sum of $\partial CVA/\partial \lambda_h$ over the CDS pillars |
| `vega_grid` | (131, 9, 9) | Model Vega, $\partial CVA/\partial\sigma_r$ |
| `xr_pilot_grid` | (131, 9) | $x_r$ values of the nodes (10th to 90th percentiles across the 10,000 outer paths) |
| `xl_pilot_grid` | (131, 9) | $x_\lambda$ values of the nodes (same percentiles) |
| `t_axis_dates` | (131,) | Rebalancing dates in years |
| `done_mask` | (131,) | Checkpoint flag, `True` for every completed date |
| `rho_r_lambda`, `rho_copula` | scalars | The correlation pair of the scenario |

## Reading a file

```python
import numpy as np

d = np.load("dual_wwr_joint_grid_citi_wwr_monthly.npz", allow_pickle=True)
print(d.files)                     # names of the arrays
print(d["cva_grid"].shape)         # (131, 9, 9)
print(float(d["rho_r_lambda"]), float(d["rho_copula"]))   # 0.4 0.4

# CVA at date index 60, x_r node 2 and x_lambda node 7
print(d["cva_grid"][60, 2, 7])
```
